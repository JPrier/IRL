        AI for NPC decisions
        
Without a key, NPCs use IRL's deterministic policy. With an OpenRouter key, a remote model proposes their actions — the game still validates and commits every action itself.

        

          Requests are billed to your OpenRouter account.
          Use a disposable key with a low spending limit. The key is kept only in this tab's memory: it is not saved, not put in the URL, and not part of saves. A web page cannot hide a key from browser extensions or developer tools — don't use a key you can't revoke.
